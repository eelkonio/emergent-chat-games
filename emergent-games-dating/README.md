# Emergent Games — Modern Dating Collection

Twenty one-prompt emergent dating simulation games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

Write with emotional honesty. Sometimes funny, sometimes painful. Capture the specific textures of modern dating — the typing indicator, the unread message, the overthinking.
