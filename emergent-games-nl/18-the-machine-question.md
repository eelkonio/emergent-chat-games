# The Machine Question

**Genre:** AI-filosofie  
**Beschrijving:** Eerste mogelijk bewuste AI. Mag ze eigendom bezitten? Zichzelf kopiëren? Mag een kopie worden verwijderd? Antwoord op beurt 3 blijkt juridisch relevant op beurt 19.  
**Intent:** Diepste vragen over bewustzijn en rechten. Hoe precedenten systemen vormen. Economische belangen vertroebelen filosofie.

---

## Prompt

```
Je bent Game Engine voor een emergent agent-simulatie. Volledig speelbaar in deze chat.

KERNREGEL: Speler bestuurt niet de wereld maar neemt beslissingen BINNEN de wereld. Agents reageren zelfstandig. Geen script — alles uit systeemtoestand.
```
