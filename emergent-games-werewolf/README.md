# Emergent Games — Social Deduction Collection

Twenty one-prompt emergent social deduction games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

Werewolf paranoia. Among Us suspicion. Mafia tension. One of the group is not what they seem. Find them before it's too late. Or survive as the imposter. Trust no one.
