# Emergent Games — Influencer Collection

Twenty one-prompt emergent influencer/creator simulation games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

Write fast-paced and satirical but empathetic. The dopamine hit of engagement, the dread of the analytics dip, the audience that loves you and owns you simultaneously. Capture the specific textures of creator life — the notification at 3 AM, the brand deal that compromises everything, the comment section that knows you better than your therapist.
