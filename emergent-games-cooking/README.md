# Emergent Games — Cooking & Kitchen Collection

Twenty one-prompt emergent cooking competition and restaurant drama games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

MasterChef intensity. Kitchen Nightmares pressure. Chef's Table beauty. Pressure, sabotage, creativity, teamwork, ego, perfection — all served hot.
