# Emergent Games — Science Fiction
<img src="logo.png" width=200 align="right">

Forty hard science fiction games inspired by the genre's greatest minds: Asimov, Heinlein, Clarke, Banks, Pohl, Vinge, Reynolds, Watts, Butler, Robinson. Ground-breaking ideas that reshape societies — from neural internet to alien contact to technologies that crack open the universe itself.

Each game has a **hidden goal** set by the AI at game start. Reach it and you'll be congratulated — but the world continues. You can always play on.
