# Emergent Games — Therapy & Psychology Collection
<img src="logo.png" width=200 align="right">



Twenty one-prompt emergent therapy simulation games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

You ARE the therapist. Clients come with real-seeming issues. Help without breaking them — or yourself. Ethical dilemmas, professional boundaries, vicarious trauma, breakthroughs. Silence is a tool. The right question matters more than any answer.
