# Logo Prompt — Emergent Games: Hackers Edition

## Image Generation Prompt

A minimalist logo for a hacker-themed game collection called "Emergent Games — Hackers Edition." The design features a stylized terminal window or command prompt with a blinking cursor, integrated with a circuit board pattern that dissolves into scattered binary/hex code at the edges. The color palette is dark — deep black background with electric green (#00FF41) as the primary accent (classic terminal green), with subtle hints of amber (#FFB000) and red (#FF0040) representing different "hat" alignments. The overall shape suggests both a shield (defense) and a skull (offense) without being explicit about either. Clean vector style, no gradients, suitable for both light and dark backgrounds. The text "HACKERS" appears in a monospace font below. The aesthetic evokes the feeling of staring at a terminal at 3 AM — focused, dangerous, alive with possibility.

## Style Notes

- Monospace/terminal aesthetic
- Circuit traces as design elements
- Binary/hex dissolve effect at edges
- Green-on-black primary palette
- Ambiguous shield/skull silhouette
- Clean, vector, reproducible
- Should work at 64x64 and 512x512
