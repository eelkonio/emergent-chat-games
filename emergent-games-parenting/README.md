# Emergent Games — Parenting Collection

Twenty one-prompt emergent parenting simulation games for your favorite chatbot. Each game uses the same engine: autonomous agents, system meters, causal feedback loops, and emergent storytelling. No scripted narratives — everything arises from the system state.

Write with warm honesty. No perfect answers exist here. Capture the specific textures of raising a human — the 3 AM feeding, the school-gate politics, the moment they say something that breaks you open with pride or worry or both.
